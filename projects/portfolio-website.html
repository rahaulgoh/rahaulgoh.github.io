Portfolio Website

A responsive, from-scratch portfolio built to showcase my projects, experiment with UI ideas, and practice clean, maintainable front-end code.

About This Project

This site started as a way to learn modern HTML, CSS, and vanilla JavaScript without relying on frameworks. I wanted something fast, minimal, and easy to maintain while still feeling polished and interactive.

Key Features

  • Flip-card project showcase with keyboard accessibility.
  • Light/dark theme toggle with preference saved to localStorage.
  • Smooth scroll, section fade-ins, and a back-to-top button.
  • Contact form wired up with EmailJS and custom notification banner.

Technologies Used

Frontend: HTML5, modern CSS (custom properties, grid, animations), vanilla JavaScript for interactivity and state (theme, nav indicator, flip cards).

Tools: EmailJS for contact form handling, GitHub for version control.

Lessons Learned

Building this site taught me how much you can do without a framework: handling state (themes, active nav links), animating UI elements, and structuring CSS so it scales well across devices without being bloated.
