StamPa - Digital Loyalty Card

Overview

Stampa is a digital loyalty card platform designed for businesses to use to allow for their customers to more easily collect and redeem loyalty points.

The main client of StamPa is smaller businesses that see more frequent returning customers

Key Features

  • Different UI for customer and business side
  • Unique loyalty cards for each business
  • Easy way to track loyalty points
  • A review section where users can potentially gain points after positing a review

Technologies Used

  • Frontend: HTML, CSS, JavaScript
  • Backend: Node.js, Express.js
  • Database: MongoDB
  • Payment Integration: Stripe API
